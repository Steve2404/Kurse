# Chapitre 17 — Drills de rappel (mémorisation)

> Première fois ? Lis d'abord le mode d'emploi [`ch17_algorithms/PARCOURS.md`](../PARCOURS.md).

Les **projets** te font **comprendre** les algorithmes. Les **drills** te font les **réécrire de mémoire**, vite et sans erreur d'indice : en entretien, et au travail, c'est ce qui compte. Ici, tu écris seulement le code ; ce sont les **tests de référence** qui le vérifient (vitesse comprise).

## Les règles d'un drill

1. **Chronomètre-toi.** Le chrono cible est en haut du `TODO.md`.
2. **Ni carte, ni Javadoc, ni solution pendant le drill.**
3. **Bloqué plus de 3 min** (5 min dans l'entretien) ? Marque ✗ et passe au défi suivant.
4. **À la fin,** ouvre la carte mémoire pour tes ✗ seulement.
5. **Avant chaque répétition,** supprime ton `RecallNN.java`.
