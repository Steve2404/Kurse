# Chapitre 1 — Projets (tableau de bord)

> Le parcours complet (projets + drills + répétition, et la règle du crescendo) est décrit dans `../PARCOURS.md`.

Chaque projet est une **application à construire de A à Z**. Dans son dossier, tu ne trouves que `TODO.md` (l'énoncé), `Check.java` (le correcteur) et `solution/` (à n'ouvrir qu'à la fin). **Tous les autres fichiers, c'est toi qui les crées.**

| ☐ | Projet | Notions | Classe `main` | Ce qui est dur |
|---|---|---|---|---|
| ☐ | `p01_receipt` — ticket de caisse | `main` et arguments, 2 classes dans un fichier, classes enveloppes, text blocks | `Receipt` | centimes affichés sans `if` ni `format` ; espaces exacts des text blocks |
| ☐ | `p02_specsheet` — fiche des primitifs | 8 primitifs, littéraux dans toutes les bases, valeurs par défaut, conversions des enveloppes | `SpecSheet` | aucune valeur tapée à la main ; débordements (`300` → `44`) |
| ☐ | `p03_bootlog` — journal de démarrage | ordre d'initialisation, lecture anticipée, portée, masquage, `var`, `final`, ramasse-miettes | `BootLog` | placer champs et blocs pour reproduire un journal exact |
| ☐ | `p04_bookshop` — application multi-paquets | paquets, imports, joker, conflit de noms, nom pleinement qualifié, `javac` / `java` / `jar` | `app.Main` + `commandes.sh` | deux classes `Book` ; construire et lancer l'appli **en ligne de commande** |
| ☐ | `p05_cinema` — **capstone** billetterie | tout le chapitre 1 | `app.Cinema` | peu d'indices ; `Integer.decode` d'un code hexadécimal |
