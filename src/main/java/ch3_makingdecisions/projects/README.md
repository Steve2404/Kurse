# Chapitre 3 — Projets (tableau de bord)

> Le parcours complet (projets + drills + répétition, et la règle du crescendo) est décrit dans `../PARCOURS.md`.

Chaque projet est une **application à construire de A à Z**. Dans son dossier, tu ne trouves que `TODO.md` (l'énoncé), `Check.java` (le correcteur) et `solution/` (à n'ouvrir qu'à la fin). **Tous les autres fichiers, c'est toi qui les crées.**

| ☐ | Projet | Notions | Classe `main` | Ce qui est dur |
|---|---|---|---|---|
| ☐ | `p01_vending` — distributeur automatique | `switch` instruction (fall-through) et expression (`yield`), `case` multiples, `if`/`else if`, boucle à indice | `Vending` | 33 commandes enchaînées ; rendu de monnaie glouton **sans tableau de pièces** |
| ☐ | `p02_numberlab` — laboratoire des nombres | `for` / `while` / `do/while`, boucles imbriquées, `continue` et `break` étiquetés | `NumberLab` | premiers, parfaits, Collatz, Armstrong, Euclide : 8 algorithmes |
| ☐ | `p03_drawing` — dessin en boucles | boucles imbriquées, géométrie des indices, `continue` | `Drawing` | losange creux, croix, table alignée, triangle de Pascal sans tableau |
| ☐ | `p04_rpn` — calculatrice RPN | pattern matching `instanceof`, portée de flux, `switch` sur `String`, for-each | `Rpn` | 4 registres `Number` ; le piège du ternaire `Integer`/`Double` |
| ☐ | `p05_robot` — **capstone** robot | `break` / `continue` étiquetés dans des boucles imbriquées, simulation | `Robot` | trois façons de sortir d'une boucle ; carte des obstacles sans tableau |
